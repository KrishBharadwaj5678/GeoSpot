<h1 align="center"><img src="https://github.com/KrishBharadwaj5678/GeoSpot/raw/main/favicon/favicon.svg" width="35"/> GeoSpot</h1>

<p align="center">
  GeoSpot позволяет легко определить ваше точное местоположение, мгновенно предоставляя текущие координаты — широту и долготу.
