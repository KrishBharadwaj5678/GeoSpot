<h1 align="center"><img src="https://github.com/KrishBharadwaj5678/GeoSpot/raw/main/favicon/favicon.svg" width="35"/> GeoSpot</h1>

<p align="center">
  GeoSpotなら、現在地の正確な緯度と経度を瞬時に取得できます。
</p>

![GeoSpotDemo](https://github.com/KrishBharadwaj5678/GeoSpot/raw/main/assets/demos/GeoSpotDemo.png)

<img src="https://github.com/KrishBharadwaj5678/GeoSpot/raw/main/assets/readme/divider.gif" width="100%"/>

## <img src="https://github.com/KrishBharadwaj5678/GeoSpot/raw/main/assets/readme/features.gif" width="35"/> 主な機能

| 機能 | 説明 |
|---|---|
| 🛰️ リアルタイム位置情報 | 現在の緯度と経度を瞬時に取得 |
| 🎯 正確な座標 | リアルタイムで正確な位置情報を提供 |
| 🚀 高速・シンプル | ワンクリックで位置情報にアクセス |
| ✨ クリーンなUI | シンプルで使いやすいデザイン |
| 📲 レスポンシブデザイン | PCやスマートフォンなど、さまざまな端末で快適に利用可能 |
